# Event Marker — Roadmap

## Fase 0 — Especificación

- Definición del producto.
- Arquitectura modular.
- Modelo SaaS.
- Templates, Renderer y Storage.
- Seguridad y SSDLC.

## Fase 1 — MVP técnico

- Identity.
- Accounts y Membership.
- Events.
- Templates y Template Manager básico.
- Invitation Editor.
- Media.
- Renderer.
- Public Invitation.
- Guest y RSVP básico.
- Planes, limits y subscription base.
- Tests y controles de seguridad.

## Fase 2 — Validación comercial

- Primeros usuarios.
- Primeras ventas.
- Medición de conversión.
- Validación de pricing.
- Validación de categorías y templates.

## Fase 3 — Optimización

- Rendimiento.
- CDN/caching cuando el tráfico lo justifique.
- Mejoras de editor.
- Optimización de imágenes.
- Mejoras de onboarding.

## Fase 4 — Professional

- Gestión de clientes mejorada.
- Flujos para diseñadores.
- Branding y capacidades profesionales.
- Gestión avanzada de eventos.

## Fase 5 — Business

- Teams.
- Roles adicionales.
- Administración empresarial.
- Capacidades de colaboración.
- White-label si existe demanda real.

## Fase 6 — Plataforma de experiencias

Posibles extensiones:

- RSVP avanzado.
- Gestión de invitados.
- Campañas.
- Analítica.
- Itinerarios.
- Galerías.
- Mesas.
- Regalos.
- Eventos corporativos.
- Marketplace de templates.

## Regla

No se implementará una fase futura solo por estar en el roadmap. Cada expansión debe validarse con necesidad de producto, usuarios y capacidad técnica.
