# Event Maker — UX del MVP

## 1. Objetivo

La experiencia de usuario debe permitir que una persona cree una
invitación digital de forma sencilla, sin necesidad de conocimientos
técnicos y sin obligarla a registrarse antes de comenzar.

El flujo principal debe ser:

Crear → Personalizar → Previsualizar → Pagar → Publicar → Compartir.

---

# 2. Principios de UX

Event Maker debe priorizar:

1. Simplicidad.
2. Claridad.
3. Progreso visible.
4. Retroalimentación inmediata.
5. Prevención de errores.
6. Confianza durante el pago.
7. Recuperación del progreso.
8. Diseño responsive.

El usuario siempre debe saber:

- dónde está;
- qué está haciendo;
- qué falta;
- qué ocurrirá después.

---

# 3. Página de inicio

La página inicial debe presentar claramente:

- qué es Event Maker;
- qué puede hacer el cliente;
- ejemplos de invitaciones;
- tipos de eventos;
- llamada principal a la acción.
